Commands for a connected car

Back to dashboard

Run these in a terminal from the elmlens folder, with the adapter plugged in.

The adapter serves one program at a time. Stop the dashboard with Ctrl+C before running another command, or the adapter won't be found.

See everything

.\obd dashboard

Live values, fault codes, self-tests and vehicle details on one page.

Needs: ignition ON or engine running.

.\obd report

Reads everything once and saves it to a text file in the reports folder.

Needs: ignition ON or engine running.

Check the car

.\obd battery

Explains the battery voltage. With the engine running, it also checks charging.

Needs: adapter powered by the car. Works even if the car's computer doesn't answer.

.\obd codes

Shows stored, pending and permanent fault codes with descriptions.

Needs: ignition ON or engine running.

.\obd info

Shows the adapter, voltage, check engine light, self-tests and available values.

Needs: ignition ON or engine running.

Live data

.\obd live

Shows live values in the terminal. Press Ctrl+C to stop.

Needs: ignition ON or engine running.

.\obd log

Records live values to a CSV file in the logs folder. Press Ctrl+C to stop.

Needs: ignition ON or engine running.

Other modules and extra values

.\obd scan

Looks for other modules and reads their fault codes where the car allows it. Takes about a minute.

Needs: at least 11.8 V. Running the engine is best.

.\obd profile --name kia-picanto --year 2017

Reads extra values using a community profile. Replace the name and year with your car's. Some values may not apply to your car.

Needs: at least 11.8 V. Running the engine is best.

Changes the car

.\obd clear

Clears fault codes after you type CLEAR. This doesn't fix the fault, and it resets the emissions self-tests.

Needs: engine off and ignition ON.

To use Arabic in any command, add --lang ar before it, such as: .\obd --lang ar report
