Car copies

A copy keeps what the car reported, so you can test Fahis with no car or adapter. It isn't the ECU's program. It includes the VIN, so keep it private.

Fahis watches the readings over the whole connection and points out patterns. These are hints from general rules of thumb, not your car maker's limits, and they aren't a diagnosis. Some need a few minutes of running to appear.

What Fahis noticed

Moments saved

When something new goes wrong, Fahis saves every reading from the half minute before and after it, so the moment can be looked at later.

Lowest, average and highest

Looking at a car you don't know? This checks for signs that faults were hidden or parts were swapped. It reads only the computers that answer, usually the engine and transmission. It can't see crash damage, mileage or wear, so it doesn't replace a mechanic's inspection.

Read only. Fahis shows what each computer reports about itself. It doesn't copy or change the ECU's program.

Car identity

ECU tools

Read all identity data asks each computer for every standard identity item it will share, which takes about a minute each. Scanning asks every possible address, which takes about a minute. Both only read, and neither unlocks anything. Copying or changing the ECU's program needs the maker's security unlock, so Fahis doesn't do it.

Terminal only

        
The adapter serves one program at a time. Stop this app with Ctrl+C before running a command in a terminal, or the adapter won't be found.

        
.\obd live
Shows live values in the terminal. On this app, use the Live data page.

        
.\obd log
Records live values to a CSV file in the logs folder. Press Ctrl+C to stop.
